## Running This Portfolio Locally

```bash
npm install
npm run dev      # Starts Express + Vite full-stack server on http://localhost:3000
npm run build    # Builds production frontend bundle into dist/
npm run start    # Serves production bundle via server.ts
```

Optional environment variables in `.env` (see `.env.example`):
- `GITHUB_CLIENT_ID` & `GITHUB_CLIENT_SECRET` — enables GitHub OAuth sign-in for private repository code browsing and direct repository pushes.
- `APP_URL` — base URL used for OAuth callback routing (`/auth/github/callback`).
